# 🍔 ZingyByte AI — Smart Serve

ZingyByte AI is an AI-powered food assistant built for the ZINGYBYTE food delivery platform.

It helps users explore the menu, get food recommendations, track orders, and answer common food delivery questions using a local AI model.

The application uses **Ollama + LangChain** to run AI locally and provides a smooth chatbot experience with a modern user interface.

---

## ✨ Features

### 🤖 AI Food Assistant
- Chat with an intelligent food assistant.
- Get answers about menu items, orders, and services.
- Powered by local LLM models using Ollama.

### 📚 Smart Knowledge System
- Uses a structured knowledge base containing:
  - Food menu details
  - Business FAQs
  - Order information

### 📦 Order Tracking
- Check order status using order IDs.
- Provides:
  - Delivery status
  - Delivery partner details
  - Estimated delivery time

### 💬 Chat Features
- Maintains conversation history.
- Automatically manages long conversations.
- Export chat history as JSON.

### 🎨 Modern UI Design
- Dark glass-style interface.
- Animated food background.
- Interactive suggestion buttons.
- Real-time AI response display.
